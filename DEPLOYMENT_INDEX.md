## 🆘 Need Help?

### Step 1: Check the Relevant Document
- Deployment issues → **DEPLOYMENT_CHECKLIST.md**
- Environment variables → **ENVIRONMENT_SETUP.md**
- Overview → **DEPLOYMENT_GUIDE.md**

### Step 2: Common Errors
- **CORS error** - Check `CLIENT_ORIGIN` in Render
- **Blank page** - Check `VITE_API_URL` in Vercel
- **API 404** - Verify Render backend URL
- **WebSocket failed** - Check `VITE_SOCKET_URL`
- **502 error** - Check Render logs

### Step 3: Google/ChatGPT
Use your error message with deployment context
